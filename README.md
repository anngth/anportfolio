# An Portfolio

Minimal personal portfolio built with React, Vite, and TypeScript.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Content

Edit portfolio content in:

```txt
content.json
```

The JSON content is validated in:

```txt
src/content.ts
```

## Deploy To Cloudflare Pages

Build locally:

```bash
npm run build
```
